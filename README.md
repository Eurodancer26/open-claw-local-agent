# Open-Claw Local Agent 🐾🤖

**Open-Claw Local Agent** — это автономный локальный AI-агент на базе **Node.js (ESM)** и **`node-llama-cpp`**, спроектированный по паттерну **Plan & Execute** с поддержкой самокоррекции (Self-Correction). Система оптимизирована для работы на дискретных видеокартах с ограниченным объёмом видеопамяти (включая **Intel Arc A580, 8 ГБ VRAM**) без отправки данных во внешние облачные сервисы.

---

## 🎯 Архитектурная концепция

В отличие от классических локальных чат-ботов, агент реализует многошаговый цикл выполнения задач:
1. **Планирование (Plan):** Декомпозиция запроса пользователя на атомарные шаги.
2. **Выполнение (Execute):** Взаимодействие с локальной файловой системой и средой выполнения через изолированный реестр инструментов (`Tool Use`).
3. **Самокоррекция (Self-Correction):** Анализ результатов выполнения и ошибок для автоматического исправления кода или параметров запуска.
4. **Потоковая прозрачность:** Отображение прогресса мышления и выполнения шагов в реальном времени через Server-Sent Events (SSE).

## 🔒 Безопасность и изоляция (Sandbox)

Поскольку агент имеет доступ к файловой системе и выполнению системных команд, в проект заложены строгие механизмы защиты:

* **Защита от Directory Traversal:** Все пути предварительно нормализуются и проверяются через `resolveWorkspacePath` — выход за пределы рабочей директории (`../`) жёстко блокируется.
* **Блокировка симлинков:** Проверка реальных путей (`fs.realpath`) предотвращает обход песочницы через символические ссылки.
* **Белый список команд (`SAFE_COMMANDS`):** Инструмент `runCommand` не принимает произвольные shell-команды. Доступны только заранее описанные безопасные идентификаторы (например, `node-version`, `git-status`, `run-test`) без прямого вызова небезопасного shell-окружения.
* **Синглтон LLM-движка:** Гарантирует загрузку модели в VRAM ровно один раз, защищая GPU от переполнения памяти (OOM) при параллельных запросах.

## 🛠 Технологический стек

* **Runtime:** Node.js v20+ (ES Modules)
* **Web Server:** Express.js
* **Inference Engine:** `node-llama-cpp` (локальный GPU-оффлоад GGUF-моделей)
* **Testing Framework:** Встроенный раннер `node:test` + `node:assert/strict`

## 📦 Установка и запуск

1. **Клонируйте репозиторий и установите зависимости:**
   ```bash
   git clone https://github.com/Eurodancer26/open-claw-local-agent.git
   cd open-claw-local-agent
   npm install
   ```

2. **Подготовьте локальную модель:**
   Скачайте GGUF-модель (рекомендуется `qwen2.5-7b-instruct-q4_k_m.gguf`) и поместите её в директорию `models/` в корне проекта.

3. **Запуск сервера:**
   ```bash
   npm start
   ```
   Веб-интерфейс будет доступен по адресу: `http://localhost:3000`

## 🔌 API Контракт

Сервер предоставляет OpenAI-совместимый эндпоинт `POST /v1/chat/completions`, поддерживающий два режима работы:

* **Потоковый режим (`"stream": true`):** Используется веб-интерфейсом (`public/index.html`) для вывода шагов агента в реальном времени через SSE (`text/event-stream`).
* **Классический JSON-режим (`"stream": false`):** Используется для программной интеграции и автоматизированных тестов. Возвращает стандартный объект `chat.completion`.

## 🧪 Тестирование

В проекте реализован единый набор тестов в `tests/run-all.test.js`:

* **Быстрые тесты безопасности, API и песочницы (без загрузки LLM в память):**
  ```bash
  npm test
  ```

* **Полный сквозной прогон (включая реальный HTTP-запрос с инференсом локальной LLM на GPU):**
  ```bash
  npm run test:llm
  ```
