# Конструкт АИ (Open-Claw Local Agent)

**Конструкт АИ (Open-Claw Local Agent)** — это автономный локальный AI-агент на базе **Node.js (ESM)** и **`node-llama-cpp`**, спроектированный по паттерну **Plan & Execute** с поддержкой автоматической самокоррекции (**Self-Correction**). 

Система оптимизирована для работы на дискретных видеокартах с ограниченным объёмом видеопамяти (включая **Intel Arc A580, 8 ГБ VRAM**) без отправки данных во внешние облачные сервисы.

---

## Архитектурная концепция

В отличие от классических локальных чат-ботов, агент реализует многошаговый автономный цикл выполнения задач:

1. **Планирование (Plan):** Декомпозиция запроса пользователя на структурированный JSON-массив атомарных шагов с выбором нужных инструментов.
2. **Выполнение (Execute):** Последовательное взаимодействие с локальной файловой системой и средой выполнения через изолированный реестр инструментов (`Tool Use`).
3. **Самокоррекция (Self-Correction):** Автоматический перехват ошибок исполнения (например, `ENOENT`), передача контекста сбоя обратно в LLM и генерация исправленного плана действий на лету.
4. **Потоковая прозрачность:** Отображение прогресса мышления, составления плана, выполнения шагов и самокоррекции в реальном времени через Server-Sent Events (**SSE**).

## Безопасность и изоляция (Sandbox)

Поскольку агент имеет доступ к файловой системе и выполнению системных команд, в проект внедрены строгие механизмы защиты:

* **Защита от Directory Traversal и префиксных обходов:** Все пути предварительно нормализуются и проверяются через `path.relative()` в `resolveSafePath` — выход за пределы рабочей директории (`../`) и обход через соседние директории с похожими именами жёстко блокируются.
* **Блокировка симлинков и Junction:** Проверка реальных физических путей (`fs.realpath`) как для целевых файлов, так и для родительских директорий предотвращает побег из песочницы через символические ссылки при чтении и записи.
* **Белый список команд (`SAFE_COMMANDS`) и `execFile`:** Инструмент `runCommand` не использует системный shell (`exec`) и не принимает произвольные команды. Выполняются только заранее описанные безопасные идентификаторы (`node-version`, `npm-version`), что полностью исключает шелл-инъекции.
* **Гибкая валидация аргументов:** Инструменты поддерживают вариативность имён параметров от LLM (`filePath` и `path`), повышая стабильность работы агента.
* **Валидация окружения и управление VRAM:** При инициализации `initLlamaEngine` проверяется физическое наличие `.gguf`-модели, а контекст настраивается с поддержкой нескольких последовательностей (`sequences: 4`) в рамках единого синглтона, исключая переполнение памяти (OOM) и ошибки `No sequences left`.

## Технологический стек

* **Runtime:** Node.js v20+ (ES Modules)
* **Web Server:** Express.js
* **Inference Engine:** `node-llama-cpp` (локальный GPU-оффлоад GGUF-моделей)
* **Testing Framework:** Встроенный раннер `node:test` + `node:assert/strict`

## Установка и запуск

1. **Клонируйте репозиторий и установите зависимости:**
   ```bash
   git clone https://github.com/Eurodancer26/open-claw-local-agent.git
   cd open-claw-local-agent
   npm install
   ```

2. **Подготовьте локальную модель:**
   Скачайте GGUF-модель (рекомендуется `qwen2.5-7b-instruct-q4_k_m.gguf`) и поместите её в директорию `models/` в корне проекта.

3. **Запуск сервера:**
   ```bash
   npm start
   ```
   Веб-интерфейс будет доступен по адресу: `http://localhost:3000`

## API Контракт

Сервер предоставляет OpenAI-совместимый эндпоинт `POST /v1/chat/completions`, поддерживающий два режима работы:

* **Потоковый агентичный режим (`"stream": true`):** Используется веб-интерфейсом и клиентами для запуска цикла **Plan & Execute & Self-Correction** с выводом прогресса в реальном времени через SSE (`text/event-stream`), завершающегося маркером `[DONE]`.
* **Классический JSON-режим (`"stream": false`):** Используется для программной интеграции и автоматизированных тестов. Возвращает стандартный объект `chat.completion`.

## Тестирование

В проекте реализован единый сквозной комплекс из 8 тестов в `tests/run-all.test.js`:

* **Быстрые тесты безопасности, API и песочницы (без загрузки LLM в память):**
  ```bash
  npm test
  ```

* **Полный сквозной прогон (безопасность, не-стриминг, SSE-стриминг, цикл Plan & Execute и самокоррекция на реальной LLM):**
  ```bash
  npm run test:llm
  ```
