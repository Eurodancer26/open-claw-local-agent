# Конструкт АИ (Open-Claw Local Agent)

**Конструкт АИ (Open-Claw Local Agent)** — это полностью автономный, приватный локальный AI-агент на базе Node.js (ESM) и `node-llama-cpp`, спроектированный по паттерну **Plan & Execute** с поддержкой автоматической самокоррекции (**Self-Correction**), гибридной маршрутизацией запросов и генерацией сводных PDF-отчётов.

Система оптимизирована для работы на дискретных видеокартах с ограниченным объёмом видеопамяти (включая **Intel Arc A580, 8 ГБ VRAM**) с защитой от переполнения VRAM через кастомный GPU-мьютекс и без отправки каких-либо данных во внешние облачные сервисы.

---

## Архитектурная концепция

В отличие от классических локальных чат-ботов, агент реализует многошаговый автономный цикл выполнения задач с разделением когнитивных функций:

1. **Нейро-маршрутизация на CPU (`NeuralSkillRouter`)**: Лёгкая рекурсивная нейро-ячейка на чистом JavaScript с сохранением кратковременного контекста (`hiddenState`). За доли миллисекунды классифицирует входящий запрос пользователя (`chat`, `file_ops`, `system_cmd`) до обращения к тяжёлой LLM.
2. **Планирование (Plan)**: Декомпозиция сложных технических запросов на структурированный JSON-массив атомарных шагов с выбором нужных инструментов и устойчивой очисткой JSON-ответов (`safeParseJsonPayload`).
3. **Выполнение (Execute)**: Последовательное взаимодействие с локальной файловой системой и средой выполнения через изолированный реестр инструментов (`Tool Use`).
4. **Самокоррекция (Self-Correction)**: Автоматический перехват ошибок исполнения (например, `ENOENT`), передача контекста сбоя обратно в LLM и генерация исправленного плана действий на лету.
5. **Потоковая прозрачность и телеметрия**: Отображение прогресса мышления, составления плана и выполнения шагов в реальном времени через **Server-Sent Events (SSE)**, а также автоматическая генерация сводных PDF-отчётов диалогов (`pdfkit`).

## Безопасность, режимы работы и изоляция (Sandbox)

Поскольку агент имеет доступ к файловой системе и выполнению системных команд, в проект внедрены строгие механизмы защиты и два чётких режима работы:

* **Строгий режим песочницы (Strict Sandbox Mode)**: Все файловые операции жёстко ограничены директорией `tests/sandbox/`. При попытке обратиться к внешним путям агент не переписывает путь молча, а возвращает явное сообщение о запрете доступа вне песочницы.
* **Свободный режим (Free Mode)**: Работа с файлами разрешена в пределах рабочей директории проекта. Если пользователь не указал путь или имя файла, агент запрашивает уточнение вместо создания случайных файлов.
* **Защита от Directory Traversal и префиксных обходов**: Все пути предварительно нормализуются и проверяются через `path.relative()` в `resolveSafePath` — выход за пределы разрешённой директории (`../`) жёстко блокируется.
* **Блокировка симлинков и Junction**: Проверка реальных физических путей (`fs.realpath`) как для целевых файлов, так и для родительских директорий предотвращает побег из песочницы через символические ссылки при чтении и записи.
* **Белый список команд (`SAFE_COMMANDS`) и `execFile`**: Инструмент `runCommand` не использует системный shell (`exec`) и не принимает произвольные команды. Выполняются только заранее описанные безопасные идентификаторы (`node-version`, `npm-version`), что полностью исключает шелл-инъекции.
* **Синхронизация сессий и управление VRAM**: Активный режим безопасности синхронизируется с историей сессии. При инициализации `initLlamaEngine` проверяется физическое наличие `.gguf`-модели, а GPU-мьютекс управляет последовательностями (`sequences: 4`) в рамках единого синглтона, исключая переполнение видеопамяти (OOM).

## Технологический стек

* **Runtime**: Node.js v20+ (ES Modules)
* **Web Server**: Express.js
* **Inference Engine**: `node-llama-cpp` (локальный GPU-оффлоад GGUF-моделей)
* **Neural Routing**: Кастомный рекурсивный перцептрон на чистом JS (`NeuralSkillRouter`)
* **Reporting**: `pdfkit` (генерация сводных отчётов о работе и телеметрии)
* **Testing Framework**: Встроенный раннер `node:test` + `node:assert/strict`

## Установка и запуск

1. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   git clone https://github.com/Eurodancer26/open-claw-local-agent.git
   cd open-claw-local-agent
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Подготовьте локальную модель:**
   Скачайте GGUF-модель (рекомендуется `qwen2.5-7b-instruct-q4_k_m.gguf`) и поместите её в директорию `models/` в корне проекта.

4. **Запустите сервер:**
   ```bash
   npm start
   ```

5. **Откройте веб-интерфейс:**
   Перейдите в браузере по адресу: `http://127.0.0.1:3000` (или `http://localhost:3000`).

## Команды и тестирование

В проекте предусмотрен набор команд для запуска сервера и проверки всех подсистем:

* **Запуск основного сервера агента:**
  ```bash
  npm start
  ```

* **Быстрые тесты безопасности, API и песочницы (без загрузки LLM в VRAM):**
  ```bash
  npm test
  ```

* **Полный сквозной прогон на реальной LLM (безопасность, не-стриминг, SSE-стриминг, цикл Plan & Execute и самокоррекция):**
  ```bash
  npm run test:llm
  ```

* **Автономный тест рекурсивного нейро-роутера (проверка CPU-классификации и памяти `hiddenState`):**
  ```bash
  node tests/test-router.js
  ```

## API Контракт

Сервер предоставляет OpenAI-совместимый эндпоинт `POST /v1/chat/completions`, поддерживающий два режима работы:

* **Потоковый агентичный режим (`"stream": true`)**: Используется веб-интерфейсом и клиентами для запуска цикла *Plan & Execute & Self-Correction* с выводом прогресса в реальном времени через SSE (`text/event-stream`), завершающегося маркером `[DONE]`.
* **Классический JSON-режим (`"stream": false`)**: Используется для программной интеграции и автоматизированных тестов. Возвращает стандартный объект `chat.completion`.
