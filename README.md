# 🤖 Open-Claw Local AI Orchestrator

Автономный локальный агент с архитектурой **«Plan & Execute»**, работающий на базе Node.js (ESM), Express и локальной языковой модели через `node-llama-cpp`, оптимизированный под потребительские видеокарты (в частности, Intel Arc с 8 ГБ VRAM).

---

## 🏗️ Архитектура проекта

Проект построен по принципам модульности, разделения ответственности и жесткого контроля потребления видеопамяти:

```text
open-claw-local-agent/
├── models/             # Директория для GGUF-моделей (например, Qwen 2.5)
├── src/
│   ├── api/            # Маршрутизаторы Express (эндпоинты chat/completions)
│   ├── core/           # Ядро движка (синглтон-сессия model & context)
│   ├── modules/        # Игровые модули агента (планировщик и исполнитель)
│   ├── config/         # Конфигурационные файлы и пути
│   └── server.js       # Главная точка входа (инициализация и запуск сервера)
├── benchmark.js        # Технический скрипт для бенчмаркинга и замеров
├── test.js             # Комплексный набор функциональных тестов
└── package.json        # Зависимости и скрипты проекта
```

---

## ⚡ Оптимизации и ключевые особенности

- **Единый синглтон-движок в памяти:** Устраняет проблему утечек VRAM и падений при параллельных или многошаговых запросах.
- **Пайплайн «План → Выполнение»:** Автоматическое разбиение сложных задач пользователя на последовательные логические шаги с последующей точечной генерацией кода или текста.
- **Интеллектуальная очистка вывода:** Фильтрация артефактов и JSON-оберток на уровне исполнителя для получения чистого кода и готовых ответов.
- **Аппаратное ускорение:** Полный оффлоад весов модели на GPU через бэкенд `llama.cpp`.

## 🚀 Быстрый старт

1. **Клонируй репозиторий и установи зависимости:**
   ```bash
   git clone <url-репозитория>
   cd open-claw-local-agent
   npm install
   ```

2. **Помести GGUF-модель** (например, `qwen2.5-7b-instruct-q4_k_m.gguf`) в папку `models/`.

3. **Запусти сервер:**
   ```bash
   node src/server.js
   ```

4. **Запусти тесты (в соседнем окне терминала):**
   ```bash
   node test.js
   # или точечный бенчмарк:
   node benchmark.js
   ```
